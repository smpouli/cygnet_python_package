This a beta version of a Python package dedicated to query the Cygnet database (https://github.com/omwn/cygnet). It automatically downloads the latest version of the database.

This package enables to explore concepts, lexemes and senses. It also possible to directly access a concept's definition in specific languages or sentence examples for listed senses. An online interface is available: https://cygnet.maudslay.eu/.

This python library can now be installed via pip:

    pip install cyg
